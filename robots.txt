# =============================================================================
# GitHub Pages 用户站robots.txt

# 位置：https://tchao8820.github.io/robots.txt
#
# 【为什么需要这个文件】
# 爬虫只读取「主机根目录」的 robots.txt。Google 官方文档明确：
#   https://example.com/robots.txt            → 有效
#   https://example.com/folder/robots.txt     → 不是有效的 robots.txt，抓取工具不会检查
#
# 本站项目 ctbu-kexie-website 位于子路径 /ctbu-kexie-website/，
# 它自己仓库里的 robots.txt 爬虫读不到，导致那些 Disallow 规则形同虚设。
# 本文件放在用户站根目录，对该用户名下所有 Pages 项目页生效。
#
# 【维护说明】
# * 本文件由手工维护，不是任何脚本的生成产物。
# * 项目仓库内的 tools/gen_seo.py 仍会生成一份项目级 robots.txt，
#   那份用于自文档化与将来绑定自定义域名后的迁移，两者不冲突。
# * 新增 Pages 项目后，请同步更新下面的 Sitemap: 行与项目屏蔽规则。
# =============================================================================
